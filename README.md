# language-os

Personal language learning operating system.

This repository is a long-term record of deliberate language practice. It is designed to remain useful for years: plain Markdown, predictable folders, small daily entries, and regular review.

## Vision

Build durable communication ability through consistent cycles of input, recall, output, and feedback.

The system should make progress visible, turn mistakes into reusable training data, and keep language learning easy to resume after interruptions.

## Current Goals

- Maintain a sustainable daily practice habit.
- Prioritize speaking and useful communication.
- Build active vocabulary through repeated recall and use.
- Review mistakes until the corrected pattern becomes automatic.
- Keep the repository simple enough to maintain for multiple years.

Update this section during weekly review. Keep goals few, specific, and observable.

## Daily Workflow

1. Choose one practical topic or situation.
2. Get targeted input: listen, read, or study a short example.
3. Recall key words and patterns without looking.
4. Produce output by speaking or writing.
5. Capture mistakes, corrections, and useful vocabulary.
6. Record the session in `journal/` using `templates/daily.md`.

The minimum viable session is one focused interaction with the language and one short written record.

## Weekly Workflow

1. Review the week’s journal entries.
2. Identify recurring mistakes and update the relevant file in `mistakes/`.
3. Select high-value vocabulary and update `vocabulary/`.
4. Re-test selected items through speaking or writing.
5. Note evidence of progress and choose the next week’s focus.
6. Record the review in `reviews/` using `templates/weekly.md`.

## Repository Structure

| Path | Purpose |
| --- | --- |
| `README.md` | System overview and operating workflow |
| `rules.md` | Stable principles for using the system |
| `journal/` | Dated daily practice records |
| `mistakes/` | Language-specific error logs and corrections |
| `vocabulary/` | Language-specific active vocabulary |
| `phrases/` | Reusable English native chunks and collocations |
| `ideas/` | Reusable personal stories for speaking and writing |
| `reviews/` | Dated weekly and periodic reviews |
| `templates/` | Reusable Markdown templates |
| `resources/` | Curated references, links, and learning material |

### Naming Convention

- Daily journal: `YYYY-MM-DD.md`
- Weekly review: `YYYY-Www.md`
- Keep language files lowercase and stable.
- Prefer append-only history; revise entries only to clarify or correct them.

## Maintenance

Keep the system small. Add a new file only when it improves retrieval, review, or decision-making. Commit meaningful changes so the repository history shows how the system evolves.
